# Constellation 0.1.38 — smoother navigation

This beta adds protection against accidental branch switches and fixes configuration-window behaviour since 0.1.33.

## Changes

- Open child fans protect their approach corridor, with a small angular margin beyond each edge. Moving toward an edge child no longer switches to an older wheel through the child's inner gap. Cross the margin to switch immediately; no hover delay is added.
- Switching universes in Settings immediately updates the preview and its warnings.
- Settings opens maximized. Opening it again also maximizes the existing window and preserves its draft.
- Corrected Windows audio callback notifications. Optional audio diagnostics are available for investigating an intermittent click; this issue is still open.

## Download and update

Download `Constellation-0.1.38-windows-x64.zip`, extract the whole folder somewhere writable and run `constellation.exe`. The adjacent `.zip.sha256` file provides its checksum. No installer is needed.

To update, save and close Settings, quit the tray app, back up your existing folder, and replace the packaged files while **preserving `data/`**. Existing configuration needs no migration. After moving the portable folder, recreate any optional Windows shortcuts.

## Known issues

- An intermittent audio click can still occur, reported on reuse after inactivity. The audio changes are not a confirmed fix.
- A rare editor selection/save issue has no reliable reproduction. Check the bottom status message if a selection cannot be changed or saved.
- Display scaling, audio devices, universe/profile persistence and the new navigation margin still benefit from hands-on testing on different setups. Automated Windows/Linux checks passed; they do not cover every desktop combination.

Windows x64 only. The executable is unsigned. Fullscreen detection is heuristic, and shortcut conflicts depend on other apps. Linux desktop integration, editable themes and application-action adapters remain future work.

Report bugs with the version and reproduction steps, omitting private paths, notes and arguments. Source is available under GPL-3.0-or-later.
