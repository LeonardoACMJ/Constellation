# Constellation 0.1.45 — visible browser settings and undo shortcuts

## Changes

- Fixes the Web browser button being covered by the Target path / URL caption. Select a universe root or URL Star to enable this setting; other Star kinds keep it disabled.
- Web browser and unsaved-changes dialogs now open centered over Settings and stay within its monitor work area.
- Ctrl+Z / Ctrl+Y undo and redo draft operations outside text fields. In text fields they use the native single-record undo/redo; new editing clears field Redo. Ctrl+S, tree Ctrl+D/F2 and shortcut recording retain their existing behaviour.

## Update

Extract `Constellation-0.1.45-windows-x64.zip` into a writable folder. To update, save/close Settings, quit the tray app, back up your portable folder and replace packaged files while preserving data/. The adjacent .sha256 file verifies the archive. Existing configuration needs no migration; .44 browser-field downgrade limits still apply.
