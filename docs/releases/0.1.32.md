# Constellation 0.1.32 — first public beta

A portable Windows radial launcher: press Ctrl+Q, move through nested Constellations, and launch a Star. This is a prerelease for feedback, not a declaration that every desktop combination has been verified.

## Included

- Global keyboard/mouse profiles with Click or Hold activation, immediate hover navigation and fullscreen suspension.
- Independent universes, a starting Constellation per profile, and per-profile item visibility.
- Programs, Windows shortcuts, folders, HTTP/HTTPS URLs and scripts; scripts can accept console input.
- Automatic/custom/software-source icons, configuration-only notes, undo/redo and JSON import/export.
- Antialiased radial, optional white-dot pointer, four synthesized sounds and None.
- Independent Add/Remove from Start menu and Enable/Disable Windows startup buttons, applied immediately without Save.

## Download and use

Download `Constellation-0.1.32-windows-x64.zip`, extract the whole folder somewhere writable, and run `constellation.exe`. Press Ctrl+Q. Configure through Settings in the sample menu or the tray icon. No installer is required. The adjacent `.zip.sha256` file records the archive checksum.

For an existing installation, save and close Configure, quit the tray app, then replace the packaged application/document files while preserving `data/`. Back up that folder first. After moving the portable folder, recreate any optional Windows shortcuts.

## Known limits and review still needed

- Windows x64 only. Linux desktop support, editable themes and program-action adapters are future work.
- The executable is unsigned; Windows may show a reputation/signature warning.
- Ctrl+Q conflicts with shortcuts in some applications; profiles are configurable. Fullscreen detection is heuristic.
- A rare editor selection/save issue has been reported and has no reliable reproduction. If an item refuses to switch/save, check the bottom status message; report the preceding steps and version without sharing private configuration.
- Manual review of multiple universes, nested entries and visibility persistence on real user configurations remains open. Mixed-DPI/multiple-monitor behavior and subjective audio quality also depend on the actual machine.
- Start menu search can take time to reflect shortcut changes. Removing its shortcut does not disable the independent Windows startup shortcut.
- Existing configurations load, but older builds may reject newer note/icon/instrument/visibility fields or multi-universe files. Preserve a compatible backup before downgrading.

Windows/Linux automated checks, native Windows regressions, release packaging and checksum validation provide partial coverage; they do not replace the pending hands-on checks. No local desktop automation was performed for publication.
