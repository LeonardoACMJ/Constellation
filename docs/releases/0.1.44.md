# Constellation 0.1.44 — browsers and easier editing

Choose a browser for each universe, carry custom icons with exported configurations, and use familiar editor shortcuts.

## Changes

- Select a universe root → **Web browser…** to choose a browser executable and optional arguments. URL Stars inherit it; each URL can choose its own browser or the system default. The URL is appended as one argument, without shell expansion. Apply to draft, then Save.
- **Ctrl+S** saves Settings or Advanced JSON. With the tree focused, **Ctrl+D** duplicates and **F2** selects the name for renaming. Text-field editing and binding recording keep their own input handling.
- Closing unsaved Settings now offers **Save / Discard / Cancel**. Invalid fields or a file conflict keep the draft open instead of closing it.
- **Export…** defaults to a portable **.constellation** bundle with referenced custom images. Choose Configuration JSON for the previous configuration-only format. Imports remain undoable draft changes and require Save. Bundles do not copy programs, scripts or From Software executable sources; image limits are 8 MiB each and 64 MiB total.

## Download and update

Extract `Constellation-0.1.44-windows-x64.zip` into a writable folder and run constellation.exe. The adjacent .sha256 file provides its checksum. When updating, save/close Settings, quit the tray app, back up the folder, and replace packaged files while preserving data/.

Existing configurations need no migration. After saving a browser preference, older builds reject the new browser field; keep a compatible copy or remove those fields before downgrading. The JSON configuration version is unchanged.

## Known issues and manual review

- The intermittent audio click and rare, unreproduced editor selection/save issue remain under investigation.
- Manually check browser/profile arguments with your installed browser, native file-dialog format/overwrite choices, the new close dialog and shortcuts on your display setup. The small-screen footer redesign is deferred.
- Windows x64 only, unsigned executable. Fullscreen detection, foreground activation, display scaling and audio devices still benefit from checks on different setups.

Linux desktop integration, editable themes and application-action adapters remain future work. Source is GPL-3.0-or-later.

Automated Windows/Linux checks passed, including browser inheritance and overrides, bundle round-trips and malformed imports, editor shortcuts, and native Save/Discard/Cancel and external-file conflict regressions.
