# Constellation 0.1.51 — palette dropdown sizing

The Palette list now fits its entries up to twelve visible rows, bounded by the monitor work area. Larger libraries use a normal scrollbar. It recalculates when palettes are loaded/saved and before opening, including after a DPI change.

Border colors are unchanged: custom palettes share one Outline color between Stars, Constellations and highlights. The original default radial retains its four historical outline shades.

Device-free sizing checks cover six entries, large libraries, limited screen space and multiple DPI scales. Native dropdown behavior remains pending manual review, alongside the [previous checks](0.1.50.md). No configuration migration.
