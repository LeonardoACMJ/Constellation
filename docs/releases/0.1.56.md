# Constellation 0.1.56 — unexpected-exit diagnostics

The resident now records startup, readiness, exit requests, message-loop termination, cleanup and Rust panic locations in a bounded portable lifecycle log. No polling thread or input recording is added.

An unexpected disappearance after playing Deadlock is under investigation. The resident was already absent when inspected, and its last foreground record no longer blocked fullscreen. No Constellation crash event was found. This build improves evidence collection; it does not claim to fix the unidentified exit.

Includes the six official palettes from 0.1.55. Existing pending manual checks remain, including intermittent audio, mixed DPI, recovery/path workflows, bundle transfer and the rare editor selection/save issue.
