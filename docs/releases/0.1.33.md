# Constellation 0.1.33 — portable package cleanup

This beta replaces 0.1.32. The launcher behavior and configuration format are unchanged; the correction cleans up what is distributed and versioned.

## Changed

- The portable ZIP contains only `constellation.exe`, `README.md`, `PORTABLE-MANIFESTO.md`, `LICENSE` and `THIRD-PARTY-NOTICES.txt`.
- Exploratory research, historical verification notes and the superseded browser experiment are local-only and ignored by Git. Developer checklists remain in the repository, outside the user package.
- Local credentials, generated caches, working notes and handoffs have explicit ignore rules. Source, tests, specification and implementation documentation remain versioned.

The manifesto advocates portable software and user autonomy, in Portuguese and English. Start menu and Windows startup actions remain independent, immediate buttons that never need Save.

## Download and update

Download `Constellation-0.1.33-windows-x64.zip`, extract the whole folder somewhere writable and run `constellation.exe`. Press Ctrl+Q. A `.zip.sha256` file accompanies the download.

To update, save and close Configure, quit the tray app, back up your existing folder, and replace the packaged application/document files while preserving `data/`. Old development documents already present in your folder do not affect operation; the new ZIP does not contain them. After moving the portable folder, recreate any optional Windows shortcuts.

The 0.1.32 release/downloads are withdrawn after this replacement is available. Git history and its source tag are preserved.

## Beta limits

Windows x64 only; the executable is unsigned. Editable themes, Linux desktop integration and application-action adapters remain future work. Fullscreen detection is heuristic and bindings may conflict with other apps; profiles are configurable.

A rare editor selection/save issue has no reliable reproduction. Check the bottom status message if a selection cannot be changed or saved. Manual validation of universes, nested entries and per-profile visibility persistence remains pending, along with machine-specific display/audio checks. The user confirmed that Start menu removal works after Windows refreshes the displayed result. Automated Windows/Linux checks provide partial coverage, not a substitute for the remaining manual checks.

Existing configuration needs no migration. Older builds may reject newer fields or multiple universes; preserve a compatible backup before downgrading.
