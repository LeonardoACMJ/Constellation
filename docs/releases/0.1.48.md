# Constellation 0.1.48 — cached invocation

- Open the radial using its existing validated configuration, without reading/parsing config.json before centering the pointer.
- Reload Settings saves and external configuration edits on a separate event-driven worker. No idle polling or intentional navigation delay. An active gesture retains its snapshot until it closes; invalid changes preserve the last valid configuration.
- Coalesce pending updates into one latest snapshot, filter unrelated portable logs/backups from directory notifications, and reject queued old gesture indices before changing bindings.
- Use a brief, bounded background retry for incomplete external writes. If directory notifications are unavailable, Settings Save still reloads; external edits require restarting, with a notice explaining the limitation.

The configuration was already resident in memory. Added resources are a sleeping worker, native events and a small notification buffer; another parsed configuration is held only while reloading or waiting for an open menu to close. No new third-party crate or configuration migration.

Device-free automated checks cover reload notifications, atomic saves, invalid-file recovery and gesture deferral. Manual opening-latency/gesture checks, 0.1.47 Task Manager→Desktop/moving-pointer checks, bundle transfer and the intermittent audio click remain pending. The rare selection/save report still awaits reproduction, and the small-screen footer redesign remains deferred.
