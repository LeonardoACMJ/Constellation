# Constellation 0.1.53-layout.1 — small-window layout preview

This optional build brings the separate layout experiment up to date with [0.1.52](0.1.52.md), including palette libraries, outline customization and subsequent regression fixes. It is not merged into main or a public release.

Save, Reload, profiles, JSON, Tools and Hide/Show preview remain in a fixed footer. The hierarchy/sidebar and item fields scroll independently inside clipped panes. Hiding the preview gives the item panel more width. Tab navigation reveals the focused field; scrolling over the preview does not reset either pane. Layout preferences are session-only.

Use a separate portable folder and copied configuration for review. Changes saved there affect only that copy. Review scrolling, narrow windows, maximize/drag-to-restore, keyboard navigation, invalid field preservation, preview toggling and DPI changes. Automated checks do not establish visual comfort or native behavior on every monitor.
