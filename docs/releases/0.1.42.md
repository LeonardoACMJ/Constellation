# Constellation 0.1.42 — duplicate and edit faster

This beta makes it easier to create similar launchers and fixes text-editing shortcuts in Settings.

## Changes

- **Duplicate** sits beside **+ Star** and **+ Constellation**. It copies a selected Star or a complete Constellation branch, including every descendant, immediately after the original under the same parent.
- Copies retain launch paths, arguments, script runners, working directories, icons, notes and visibility settings. Every copied node gets a fresh ID; editing a copy does not change its source. The copied root gains “(copy)” in its name and is selected for quick renaming. The universe root is excluded.
- Duplication supports Undo/Redo and requires **Save** to persist. Valid pending item edits are applied first; invalid fields remain available for correction.
- **Ctrl+A** now selects all text in the active configuration field. **Ctrl+Backspace** deletes selected text or the previous word instead of inserting an invisible control character. Deletions support native field Undo; read-only fields remain protected, including the item path.

## Download and update

Download `Constellation-0.1.42-windows-x64.zip`, extract the whole folder somewhere writable and run `constellation.exe`. The adjacent `.zip.sha256` file provides its checksum. No installer is needed.

To update, save and close Settings, quit the tray app, back up your existing folder, and replace the packaged files while **preserving `data/`**. Existing configuration needs no migration. After moving the portable folder, recreate any optional Windows shortcuts.

## Known issues

- An intermittent audio click remains under investigation, particularly on reuse after inactivity.
- A rare editor selection/save issue has no reliable reproduction. Check the bottom status message if a selection cannot be changed or saved.
- Shortcuts with unavailable or unusual icon sources may retain the Windows fallback icon. Custom images and Symbol remain available.

Windows x64 only; the executable is unsigned. Fullscreen detection is heuristic, and shortcut conflicts depend on other apps. Display scaling, audio devices and universe/profile persistence still benefit from testing on different setups. Automated Windows/Linux checks, independent-copy and history regressions, native button interactions and text-field shortcut/Undo checks passed.

Linux desktop integration, editable themes and application-action adapters remain future work. Report bugs with the version and reproduction steps, omitting private paths, notes and arguments. Source is available under GPL-3.0-or-later.
