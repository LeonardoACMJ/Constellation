# Constellation 0.1.43 — safer configuration and responsive launching

This beta protects drafts and profile entry points, refreshes item icons, and moves target checks and launch work away from the input thread.

## Changes

- Save detects external changes to config.json and keeps the draft instead of silently overwriting the file. Export the draft separately before Reload to reconcile a conflict. Advanced JSON uses the same protection.
- Deleting a branch containing a shortcut profile’s entry point now names the dependent profiles and leaves the draft unchanged. Change Opens at before deleting it.
- Backup recovery shows an informational tray notice and a persistent marker in Settings. The damaged original remains until explicit repair.
- The bounded icon cache counts distinct images, prioritizes active branches and shares repeated sources. Later use refreshes stale images and retries failures; Save/Reload forces a refresh. Old asynchronous results cannot overwrite new requests.
- Availability advice and target launching run in background workers with bounded work queues. Renames and other nonstructural edits retain native tree items; notes and sound changes no longer rerasterize the full preview.

## Download and update

Extract `Constellation-0.1.43-windows-x64.zip` into a writable folder and run constellation.exe. The adjacent .sha256 file provides its checksum. To update an existing copy, save and close Settings and quit the tray app, back up the portable folder, then replace packaged files while preserving data/. Existing configuration needs no migration.

## Known issues and manual review

- The intermittent audio click and rare, unreproduced editor selection/save issue remain under investigation.
- Review conflicts/recovery in a disposable copy, profile-entry deletion, icon refresh in large trees, and responsiveness with slow/mapped drives. Foreground activation still depends on Windows and the target application.
- External-change detection checks the file before writing and again before replacement; it is not a lock against unrelated tools writing at exactly the same time.
- Windows x64 only, unsigned executable. Display scaling, audio endpoints, fullscreen detection and shortcut conflicts still benefit from checks on different setups.

Linux desktop integration, editable themes and application-action adapters remain future work. Source is GPL-3.0-or-later.

Automated Windows/Linux checks passed, including native tree/dialog regressions, stale-result rejection, external-save conflicts and the bounded launch queue. A hidden Windows debug-build measurement with 10,001 tree items recorded 522 ms for construction and 177 ms for a rename refresh, with zero recreated items; it excludes preview rasterization and display scanout. These timings are a CI sample, not a hardware-independent latency guarantee.
