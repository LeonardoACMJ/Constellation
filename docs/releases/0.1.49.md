# Constellation 0.1.49 — editor tools and recovery

- Choose a preset or edit individual colors in **Tools → Themes & colors**. Changes preview there, join the editor draft, and reach the launcher on Save. Reset restores the original palette.
- Move several items between Constellations or universes with **Tools → Move items**. Search destination paths; Ctrl/Shift selects multiple sources. A selected branch includes its children. The move is one Undo step and preserves IDs and profile dependencies.
- Review missing targets, working directories and icon/browser sources with **Tools → Check / repair paths**. Preview an old-folder → new-folder replacement before applying it. No target is launched; URLs, arguments and notes are untouched.
- Keep one bounded, portable recovery document for unfinished edits, including invalid field text and owned-dialog drafts. Restore/Discard is explicit; recovery never becomes the live configuration automatically. Saved/Unsaved state and browser inheritance are clearer.
- Prepare full-preview geometry and warnings on a latest-only worker. Reuse indexed nodes for icons and avoid cloning/validating the entire tree on every slider change.
- Scale editor controls/fonts with monitor DPI and honor Windows high contrast. Keyboard-only radial navigation remains outside this change.
- Retry audio output on a later note after a transient device failure, with bounded backoff. Between phrases, detect a changed preferred output. Opt-in audio tracing adds refill-delay and starvation events. This does **not** establish that the intermittent click is fixed.
- Require explicit interactive-session opt-in and fixture-owned windows in legacy desktop probes; strengthen correctness linting, documentation checks and portable archive verification.

Includes 0.1.48's event-driven configuration reload and cached invocation; see [the previous notes](0.1.48.md).

**Compatibility:** default themes add no configuration field. A custom palette writes `theme`; older builds reject that field. Keep a compatible copy before downgrading, or reset the palette and Save. Configuration version stays unchanged. Recovery is a separate `data/editor-draft.json` document, limited to 16 MiB, and contains unfinished text; it is excluded from release packages and exports.

**Pending manual review:** recovery of unapplied/invalid text after an abnormal exit, theme colors/Undo/Save, multi-item and cross-universe moves, path replacement preview, mixed-DPI/high-contrast behavior, and actual audio-device switching/listening. Cached opening, Task Manager→Desktop/moving-pointer checks and manual bundle transfer remain pending. The rare selection/save issue still awaits reproduction. The Overwatch-minimized report cleared after restarting a resident that was no longer running; its original exit cause is unconfirmed. The small-screen layout experiment is isolated from this build.
