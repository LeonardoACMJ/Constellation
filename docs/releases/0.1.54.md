# Constellation 0.1.54 — separate Star label color

Themes & colors now offers **Star text**. Choose a label color for Stars while Constellations, the hub and editor retain the main Text color. Leave it blank or use Auto to inherit Text, preserving existing palettes. The radial, full preview and theme preview use the same choice. Windows high contrast overrides it while enabled.

The optional `star_text` palette field is retained by saved palettes, configuration import/export, Undo/Redo and recovery of unfinished theme fields. No configuration/library version bump or migration is required for older data. Older builds reject a configuration or named-palette library that contains this new field: back up both `data/config.json` and `data/palettes.json` before downgrading, or remove the override and re-save the affected palettes.

Includes the [0.1.53 editor layout](0.1.53.md). Previously pending manual audio, mixed-DPI, recovery and path-organization checks remain open; this visual change does not establish those issues as resolved.
