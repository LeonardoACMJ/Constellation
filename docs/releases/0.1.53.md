# Constellation 0.1.53 — a more usable configuration window

The reviewed small-window layout is now part of the normal app. Save, Reload, shortcut profiles, Advanced JSON, Tools and Hide/Show preview stay in a fixed footer. The hierarchy/sidebar and item fields scroll independently. Hiding the preview gives the item fields more width, without applying or discarding pending edits. Tab/Shift+Tab reveal the focused field; scrolling over the preview leaves pane positions intact. These view choices are session-only.

This build includes the palette libraries and outline controls from [0.1.52](0.1.52.md). Configuration format and saved palette data are unchanged. The lighter Starry Night concepts are design proposals, not changes to your saved themes.

Release qualification can reuse a successful main build for the identical tagged commit when both Windows/Linux jobs passed and its portable artifact remains available. The tag rechecks source qualification and package integrity. Otherwise it runs the complete matrix.

**Review:** the user approved the separate layout preview after testing. Device-free layout checks and remote Windows native pane/modal regressions passed for the integrated implementation. Actual mixed-DPI/high-contrast ergonomics, draft recovery after an abnormal exit, path-repair/move flows and audio-device listening checks remain pending as described in [0.1.49](0.1.49.md). The intermittent audio click and rare selection/save report are not established as resolved.
