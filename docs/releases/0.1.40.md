# Constellation 0.1.40 — clearer menu editing

This beta makes larger menus easier to organize and removes Windows shortcut badges from supported automatic icons.

## Changes

- Settings now uses an expandable tree with subtle lines connecting parents and children. Several branches can stay open, and items retain their configured order and star symbols.
- The full path of the selected item appears above its fields. It can be selected, copied and scrolled horizontally, including when several items share a name.
- Expansion, selection and scrolling are remembered separately for each universe while Settings remains open. Editing and Save preserve your place; new items reveal their ancestors. Collapsing a branch containing the selected item selects that ancestor.
- Automatic icons for local `.lnk` and `.url` shortcuts use the underlying executable/image resource without the Shell-added document corner or arrow when extraction is available. From Software also supports clean shortcut icons. Launching still uses the original shortcut and its arguments.

## Download and update

Download `Constellation-0.1.40-windows-x64.zip`, extract the whole folder somewhere writable and run `constellation.exe`. The adjacent `.zip.sha256` file provides its checksum. No installer is needed.

To update, save and close Settings, quit the tray app, back up your existing folder, and replace the packaged files while **preserving `data/`**. Existing configuration needs no migration. After moving the portable folder, recreate any optional Windows shortcuts.

## Known issues

- An intermittent audio click remains under investigation, particularly on reuse after inactivity.
- A rare editor selection/save issue has no reliable reproduction. Check the bottom status message if a selection cannot be changed or saved.
- Shortcuts with unavailable or unusual icon sources may retain the Windows fallback icon. Custom images and Symbol remain available.

Windows x64 only; the executable is unsigned. Fullscreen detection is heuristic, and shortcut conflicts depend on other apps. Display scaling, audio devices and universe/profile persistence still benefit from testing on different setups. Automated Windows/Linux checks, native tree interactions and shortcut icon comparisons passed.

Linux desktop integration, editable themes and application-action adapters remain future work. Report bugs with the version and reproduction steps, omitting private paths, notes and arguments. Source is available under GPL-3.0-or-later.
