# Constellation 0.1.49-layout.1 — isolated layout experiment

This optional build adds a fixed action/status footer, independently scrolling sidebar/item panes, and Hide/Show preview. It is separate from the normal 0.1.49 build and not merged into main.

Use a disposable configuration to review resizing, pane scrolling, keyboard navigation, preview toggling and DPI changes. Pure layout/editing tests pass; native visual/interaction review remains pending. No personal configuration is included in the package.

All normal [0.1.49 features and limitations](0.1.49.md) apply.
