# Constellation 0.1.57 — icon appearances and official themes

Since the previous public beta (0.1.52):

- **Icon appearances:** choose Folder + icon, Constellation (3 stars), Star frame or Original in the item panel. Appearance is separate from the source and launch target, and works with software icons, custom images and automatic website icons. Select the appearance, then **Update draft → Save**.
- **Six built-in themes:** Constellation, Forest, Rose dusk, Daylight, Starry Night and Gracidea now ship with the app. Starry Night uses luminous gold Stars and blue Constellations. Modified older library entries are preserved as custom palettes.
- **Independent Star label color:** bright Star fills can use dark labels while Constellation labels keep the main Text color. Blank/Auto inherits Text.
- **Compact configuration window:** fixed footer, independently scrolling hierarchy and item fields, and Hide/Show preview to give the editor more room. View changes preserve unapplied edits.
- **Unexpected-exit diagnostics:** a bounded portable lifecycle log records startup, requested exits, cleanup and Rust panic locations without typed keys, window titles or panic payloads.

Icon composition runs in the background and uses the existing bounded cache. The radial and full preview share the result. Appearance survives undo/redo, duplication, draft recovery and configuration/bundle transfers. Original retains the source; missing sources and Symbol mode keep their normal symbol. Bundles never include software executables.

**Updating and downgrading:** extract into your existing portable folder while the app is closed, preserving `data/`. New builds read older configs. Untouched nodes do not gain icon_style; older builds reject nondefault icon_style and the optional star_text palette field. Back up both `data/config.json` and `data/palettes.json` before downgrading.

**Known issues and pending checks:** the unexpected resident exit after gaming remains under investigation; diagnostics are not a claimed fix. Intermittent audio, mixed-DPI ergonomics, recovery/path workflows, bundle transfer and the rare editor selection/save issue still have pending real-use checks. The Windows executable is unsigned.
