# Constellation 0.1.50 — reusable palettes

- Fix the Palette label overlapping and obscuring the theme selector. Theme-tool buttons now use the editor's colors.
- Save named palettes in **Themes & colors → Name → Save palette**. Saved palettes appear alongside the built-in presets and survive restarting or copying the portable folder. Reusing a name changes the button to **Replace palette**.
- Saving a palette is an explicit, immediate library action; it does not activate colors or save unrelated configuration edits. **Use palette in draft → Save** still applies colors to the launcher.

The library is `data/palettes.json`, separate from config.json and excluded from exported configurations/release packages. A copied whole portable folder includes it. Malformed/unsupported libraries are reported and preserved. Older builds ignore the library; active custom-theme compatibility from [0.1.49](0.1.49.md) still applies.

Pending manual review: theme-window readability, named-palette save/reopen/replace, plus the [0.1.49 validations](0.1.49.md). No local interactive tests. The optional compact-layout experiment remains unmerged.
