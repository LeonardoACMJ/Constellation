# Constellation 0.1.52 — palette outline control

Themes & colors now exposes four outline colors: inactive Star, inactive Constellation, highlighted Star and highlighted Constellation. Each can be set independently. Leave one blank or use **Auto** to derive a darker, blue-shifted color from the base Outline and matching sector fill. Live radial and fan-out previews use the same four values. The default palette preserves its original shades; Forest, Rose dusk and Daylight have their own combinations.

This version also carries the 0.1.51 palette dropdown sizing: up to twelve entries fit within the monitor work area, with a scrollbar for larger libraries.

Existing configurations and palette libraries load without changes; omitted overrides are derived automatically. Saving a non-default theme or named palette can add outline fields that older builds reject. The configuration and palette-library format versions stay unchanged. Preserve both `data/config.json` and `data/palettes.json` before downgrading.

The Gracidea palette was visually reviewed in the installed radial. Earlier manual validations remain listed in the [0.1.51 notes](0.1.51.md).
