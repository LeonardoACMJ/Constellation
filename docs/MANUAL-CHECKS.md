# Constellation 0.1.19 — manual checks

Desktop automation is paused while the user uses the PC. These checks exercise the current changes without an agent controlling input.

If Quit fails in an older build, save and close Configure, then end the resident `constellation.exe` in Task Manager before updating.

When updating, close Configure and choose **Quit** in the current tray app. Copy the files from the ZIP's `Constellation` directory into your existing app directory, keeping `data/`. Do not start a separate empty staging folder if you want to keep your existing settings. The configuration title should show **0.1.19**.

Start `constellation.exe`; right-click its tray icon → **Configure / Visualize…**. Settings persist with **Save**. Profile changes need **Done**, then **Save** in the main editor.

| Check | Steps | Expected |
|---|---|---|
| Smooth radial appearance | Open over light and dark windows; inspect arcs, diagonals, text and symbols. Repeat at available display scaling settings. | Smooth transparent edges without a black/white matte. Subtle darker blue-shifted outlines and tiny white stars; decorations remain stationary while hovering. Geometry and selection remain unchanged. |
| Item icons | Select a program/shortcut/script/folder and use Icon: Automatic → Apply item → Save. Open the radial and preview. Then use Image… to choose a PNG/ICO; Apply item → Save. Try Symbol, switch items, reopen Configure, and test undo/redo. | Automatic Windows icons load without blocking navigation. Custom image persists and is stored inside data/icons. Symbol restores the Star/Constellation symbol. Missing/bad images fall back safely; custom failures have a small inline warning. Existing selection geometry, dots/chimes and list symbols remain usable. |
| Item notes | Enter notes on root, a nested Constellation and a Star. Type/paste past 140 characters and paste a newline. Apply, switch items, undo/redo, clear, Save/reopen, export/import. Sweep noted and empty sectors, then launch normally. | Live counter and immediate single-line cap; empty JSON fields omitted. Notes persist for every node type. Central panel stays fixed with immediate updates, no tooltip delay; launch/hit geometry and independent missing-target advice remain intact. Review readability/sector overlap at your DPI. |
| Software icon source | On a script Star, choose Icon: From Software → Browse… and select the Hydrus EXE or a shortcut. Apply item → Save, then reopen Configure and inspect the radial. | The selected software icon persists; launching still runs the original instance script. Missing source falls back to the symbol. |
| App and tray icons | Inspect the executable in Explorer, its tray icon, Configure title bar and Alt+Tab. Open a nested Constellation and compare the preview. | Mint four-point app icon; one mint star for Stars and three smaller lavender stars for Constellations/root in the radial/preview; configuration lists use a single hollow star for Constellations. Check readability over light/dark taskbars and available scaling settings. Explorer may retain an old cached executable icon; do not restart Explorer solely for this check. |
| Tray menu responsiveness | Open the tray menu with right-click, dismiss with Escape and with an outside click, then reopen. Try Pause/resume, Configure and Quit. | No prolonged input blackout; the menu dismisses normally, Pause/resume works, opening Configure restores shortcut availability after dismissal, and Quit exits. Ctrl+Q while the menu is open must not open a second overlay or steal its focus. |
| Tray Quit | Close Configure, right-click the tray icon → Quit. Check Task Manager, then start the same executable again and try Ctrl+Q. Repeat Quit after using the radial. | Resident exits, tray icon disappears, shortcut stops intercepting input; restarting succeeds without an already-running warning. |
| Editor scrolling | Make the editor short enough to scroll. Wheel up/down slowly, then quickly; drag the vertical/horizontal scrollbars. | No whole-form flash, overlapping/duplicated fields or preview-header jumps; the painted panel outlines move with their contents. Resize small → maximize → restore and repeat. |
| Isolate first-restore click pause | Start a fresh Configure session. Quit the tray process while leaving Configure open, then maximize → restore once. Compare against a fresh session with the tray active. | Report whether the pause needs the tray process. Pointer smoothness alone does not distinguish slow input delivery from mouse capture. |
| Fullscreen after input change | With the tray active and a fullscreen program focused, press Ctrl+Q. Exit fullscreen and retry. | Fullscreen gets the input; the radial stays closed. Afterward Ctrl+Q opens normally and selection works. |
| First drag from maximized | Start a fresh Configure session, maximize it, then drag its titlebar to restore and move it. Release the mouse; click a field and another app. Repeat from a fresh session and once with the tray quit. | No several-second click blackout; normal pointer capture ends when the drag finishes, and fields/other apps accept clicks immediately. Test dragging specifically, not only the Restore button. Also resize by dragging each edge/corner; releasing a border must immediately restore normal clicks. |
| Maximize/restore responsiveness | Repeatedly maximize → restore, including after scrolling. Then click a field, type, scroll and close Configure. | The restored window responds immediately; no persistent stall. |
| Maximized layout | Maximize the editor after scrolling a small window. Restore it, then maximize again. | Unneeded scrollbars disappear, scroll offsets reset to zero, and the tree, item column and preview use the available width/height. |
| Editor appearance | Inspect the main editor, Shortcut profiles and Advanced JSON. Tab between controls and open dropdowns. | Related navy/teal/lavender styling, readable text, visible focus, usable fields/buttons and no clipped bottom actions. Some system-owned dialogs/chrome retain Windows styling. |
| Slider drawing | Drag each spacing slider rapidly; use arrows and Tab too. | No white flashing; dark background, readable thumb and visible keyboard focus. |
| Preview updates | Change each spacing slider, then type a value. Switch the monitor preview, resize the window and scroll. | Layout/warnings update when values change; scrolling alone reuses the same preview. Save remains available with advisory overflow warnings. |
| Intermittent chime crackle | At comfortable low volume, try an isolated selection after several seconds of silence, quick sweeps through nested branches, and another burst after a short pause. Repeat while ordinary apps are busy. | Notes/tails remain clean without isolated pops or a lagging-stream sound. Report whether a problem affects the first note after silence, a rapid sequence, or other apps' audio too. This remains a subjective device check; automated PCM tests cannot certify it. |
| Chime overlap | Enable Chimes, set a comfortable low volume, Save, then sweep across several Stars quickly. Stop moving; test mute afterward. | Single notes and overlapping tails sound clean, without the reported crunch/crackle, clipping or obvious volume pumping. A new note does not cut off the preceding note; staying on one item does not repeatedly chime. |
| White-dot cursor | Open Ctrl+Q over light/dark apps. Move through sectors, gaps and beyond the outer edge within the invocation work area. Cancel with Escape/right click; test a launch, empty Hold release and switching to another app. Disable the profile checkbox → Apply profile → Done → Save and repeat. | White dot stays smooth and stable across blank areas; its center selects. No focus takeover or persistent pointer change after closing. The unchecked profile keeps the system cursor. Check DPI scaling and cursor-end choices too. Outside the invocation work area, Windows controls the pointer normally. |
| Cursor end | In Shortcut profiles, try each **Cursor on close** choice: Restore original, Return to menu center, Leave at selection. Test launch and Escape; optionally repeat with Hold. | Original position, invocation monitor's usable center, or selection position respectively. Cursor does not recenter during branch navigation. |
| Opening without focus takeover | Focus an ordinary app and invoke Ctrl+Q. Hover a Star, then cancel with Esc; repeat with click/Space and any configured Hold profile. Open again, then switch to another app before selecting. | Radial opens without the focus-denied notification; the original app keeps focus; selection/cancel inputs do not activate its controls. Switching apps closes the radial and a late Hold release cannot launch. Fullscreen still blocks invocation. |
| Reopening | Hover Everyday → Calculator, launch it, then Ctrl+Q again. Repeat after closing an expanded branch with Escape. | The newly opened menu starts at the root with no flash of the previous expanded branch. |
| Outside targeting | Enable **Select by direction beyond the outer edge** for a profile. Move beyond a Star's outer edge in its direction; click or press Space. Repeat in a nested fan and, if configured, with Hold release. | The matching visible item stays highlighted and launches once. Painted sectors take precedence; gaps and the root hub stay neutral. |
| Exact targeting option | Disable that option, Save, then repeat outside the circle. | Outside positions stop targeting Stars; the drawn outer edge is the selection boundary. |
| Close owned dialogs | Open Shortcut profiles, then close using X; reopen and try Alt+F4, Cancel and Done. Open Advanced JSON and close using X. | Main editor responds afterward and dialogs can be reopened. X/Cancel discard profile-only draft edits; Done keeps them for main Save. Closing the main editor with unsaved changes still asks before discarding them. |
| Save mouse binding | Record a middle/side mouse button; Apply profile → Done → Save. Reopen profiles and test its Click/Hold behavior. | Recorded identity (Mouse3/4/5) persists, buttons remain usable, and saving does not strand a disabled owner. |
| Closing configuration | Close the configuration panel. | The editor process exits and releases its fonts, drawing buffers and preview cache. The separate tray process remains available. |

To create a branch: select **Your universe** → **+ Constellation**, name it → **Apply item**. With it selected, add a **+ Star**, choose its target kind and Browse to a program; Apply. Select the Constellation again to add a nested Constellation. **Parent constellation** moves existing items. **Save** before testing Ctrl+Q.

The white-dot cursor can be disabled per shortcut profile. Subjective audio quality and actual display flicker still require these manual checks.

If maximize → restore still stalls, close Configure and launch the same installed executable with `--configure --trace-editor`. Manually maximize/restore once and inspect `data/editor-trace.log` in the app folder. It records elapsed timestamps around resize, scrollbar, control placement and preview painting, capped at 4,096 entries. No configuration values or target paths are recorded. This mode is optional and creates no hooks or input automation; ordinary launches do not open the trace file. A missing `.end` identifies the last unfinished stage; repeated resize events suggest queue churn. Timing under diagnostics includes log-write overhead and is not a latency benchmark.
